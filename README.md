Breakout Game
A fully functional Breakout clone built in C# as my Grade 12 Computer Science culminating project.
 About the Game
Control a paddle, bounce the ball, and destroy all the bricks to win. Simple concept, but building it from scratch taught me more than any textbook could.
 Features

Smooth paddle and ball movement
Brick collision detection
Menu screen
Score tracking
Multiple game states (menu, playing, game over)

 Built With

C# — Windows Forms
Visual Studio

 How to Run

Clone or download this repository
Open the .sln file in Visual Studio
Hit Start to build and run

 What I Learned
This was my first major solo programming project. Building it taught me:

Object oriented programming in C#
Game loop logic and frame timing
Collision detection
Breaking a big problem into smaller classes (Ball, Paddle, Brick, Menu)
Using Git and GitHub for version control
